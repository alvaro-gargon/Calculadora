# Calculadora
Codigo de calculadora hecha a mano con las caracterisitcas básicas de las calculadoras sin IU. 
Funciones que presenta:
- Raíces cuadradas
- Raíces enésimas
- Exponentes enteros
- Exponentes generales (enteros y decimales)
- Factorial
- Funcion exponencial  (e^x)
- Logaritmos neperianos/naturales.
